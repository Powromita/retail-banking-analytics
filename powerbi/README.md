# Power BI dashboard

Power BI Desktop (Windows) is needed to author the `.pbix`. Everything it needs is generated by the pipeline,
so building it takes about 20 minutes.

## 1. Load the data
`Get Data > Text/CSV`, load the four files from `powerbi/data/` (run `python run_pipeline.py` first):

| Table | Grain | Key columns |
|---|---|---|
| `dim_customer` | 1 row per customer | churn_prob, is_at_risk, clv, segment, profit, next_best_product, recommended_action |
| `fact_monthly_activity` | customer x month | txn_count, digital_logins, card_spend, credit_utilization |
| `fact_products` | customer x product | product, balance, credit_limit |
| `dim_month` | 1 row per month | month, month_start |

Set `dim_month[month_start]` to **Date** and mark `dim_month` as a date table.

## 2. Relationships (Model view)
- `dim_customer[customer_id]` 1 → * `fact_monthly_activity[customer_id]`
- `dim_customer[customer_id]` 1 → * `fact_products[customer_id]`
- `dim_month[month]` 1 → * `fact_monthly_activity[month]`

All single direction, from dimension to fact.

## 3. Measures and theme
- Paste `measures.dax` (26 measures plus the `Utilization Band` calculated column).
- `View > Themes > Browse for themes` and pick `theme.json`.
- Sort `dim_customer[tenure_band]` and `[age_group]` with a helper sort column, or set them in order in the visual.

## 4. Pages
**Page 1, Executive overview.** Cards: Total Customers, Churn Rate %, Net Profit, Profit Margin %, Avg CLV, Profit at Risk %, Avg Products per Customer, Digital Adoption %.
Visuals: Net Profit by `segment` (bar), Churn Rate % by `tenure_band` (column), Total Card Spend by `dim_month[month_start]` (line).
Slicers: `city`, `preferred_channel`, `age_group`.

**Page 2, Churn and risk.** Churn Rate % by `Utilization Band`, At-Risk Customers by `risk_band` (donut),
scatter of `profit` vs `churn_prob` coloured by `segment`, and a table of the save list
(`customer_id`, `churn_prob`, `profit`, `clv`, `recommended_action`) filtered to `segment = High-Value At-Risk`.

**Page 3, Segments and cross-sell.** Matrix of `segment` against `fact_products[product]` (customer count),
Cross-Sell Opportunities by `next_best_product`, and a drill-through table of target customers.

Add a drill-through from Page 1 segments to Page 3.
